# Joguinho — mundo aberto

Direção livre por uma cidade 3D no navegador (React + Three.js), com modo noite e controles por teclado ou botões na tela.
É o protótipo de arquivo único que deu origem ao [corrida](https://github.com/cantsixsix/corrida); aqui a ideia é explorar, sem pista nem monstro.

## Rodar

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # versão de produção em dist/
```

Controles: **W/↑** acelera · **S/↓** freia/ré · **A/←** e **D/→** viram.

Ideias e variações: [IDEIA.md](IDEIA.md).
